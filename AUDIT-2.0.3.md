# Аудит GeniaProxy 2.0.3

Дата: 2026-08-09

## Итог

Кодовая база уже имеет хороший защитный фундамент: локальный inbound,
проверка SHA-256 ядра, атомарная запись, восстановление системного прокси,
ограничения ZIP/JSON, Job Object, single-instance и ограниченный журнал.
Версия 2.0.3 устраняет два наиболее существенных остаточных риска: нарушение
транзакции при откате ядра и несовместимость с современными WireGuard
конфигурациями sing-box.

## Исправлено

### Обновление и откат ядра

- выбранный `sing-box.exe` сначала копируется во временный файл в папке
  ядра; версия и SHA-256 проверяются именно у устанавливаемой копии;
- устранено окно подмены исходного файла между проверкой и установкой;
- все отменяемые операции отката завершены до изменения рабочего ядра;
- при сбое отката приложение пытается вернуть рабочий файл, backup и прежний
  файл контрольной суммы в согласованное состояние;
- временная проверенная копия сохраняется до завершения транзакции.

### Совместимость с sing-box

- WireGuard `endpoints` больше не удаляются из импортируемой конфигурации;
- разрешён endpoint-only профиль без обязательного массива `outbounds`;
- число endpoints ограничено, каждый элемент обязан иметь непустой `type`;
- пока разрешён только `wireguard`: другие endpoint-типы отклоняются явно,
  поскольку могут создавать системные интерфейсы или фоновые службы;
- `experimental`, `services` и пользовательские inbounds по-прежнему
  удаляются; создаётся один mixed inbound на `127.0.0.1`.

### Сопровождение

- версия повышена до 2.0.3;
- имя release-архива формируется из `Version` в `.csproj`, поэтому больше не
  требует отдельного ручного изменения;
- SDK зафиксирован на .NET 10.0.302 с roll-forward внутри новых feature bands;
- заголовок окна берёт версию из метаданных приложения;
- добавлены две регрессионные проверки endpoint-политики.

## Проверено в доступной среде

- XML обоих проектов и `global.json` синтаксически корректны;
- SHA-256 bundled-ядра совпадает с `engine/sing-box.sha256`;
- в исходниках и публикационных правилах нет пользовательских профилей;
- сетевой inbound генерируется только на `127.0.0.1`;
- архив исходников успешно проходит проверку целостности ZIP.

Полная компиляция WinForms и запуск `sing-box.exe` требуют Windows и .NET SDK
10.0.302; Linux-среда аудита не содержит .NET SDK и не исполняет Windows PE.

## Оставшиеся риски и план на год

1. Добавить Windows CI для `dotnet build`, встроенных тестов и smoke-test
   release-архива при каждом изменении.
2. Добавить подписанный manifest обновления ядра: версия, URL, SHA-256 и
   проверяемая цифровая подпись. Сейчас пользователь сам выбирает EXE.
3. Ввести явный безопасный режим для новых endpoint-типов после отдельного
   анализа их привилегий и сетевых listeners.
4. Разделить `Form1.cs` на контроллер подключения, хранилище профилей и UI:
   это упростит тестирование гонок запуска/остановки без WinForms.
5. Добавить интеграционный тест аварийного завершения с проверкой восстановления
   системного прокси в отдельном Windows-пользователе/VM.

## Ориентир актуальности

.NET 10 является LTS и поддерживается Microsoft до ноября 2028 года. Для
сохранения поддержки необходимо регулярно переходить на актуальные patch SDK и
runtime. В sing-box продолжаются удаления устаревших полей, поэтому проверка
конфигурации bundled-ядром перед каждым запуском должна оставаться обязательной.
