# GeniaProxy 4.2.1 HF2 branding

The application icon is derived from the blue/cyan GP concept sheet supplied by the project owner in the GeniaProxy project conversation on 2026-08-15.

HF2 uses the minimal GP mark on the existing GeniaProxy navy background (#071521) so it remains legible in Windows taskbar/tray sizes. The interface palette itself is unchanged.

Included icon sizes: 16, 20, 24, 32, 40, 48, 64, 128 and 256 px.
