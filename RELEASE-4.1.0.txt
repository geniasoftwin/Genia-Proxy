GeniaProxy 4.1.0
Дата: 2026-08-12

Главное изменение
-----------------
Клиент теперь работает с двумя ядрами: sing-box и Xray. В режиме
«Автоматически» ядро выбирается по формату профиля. Ручной выбор не выполняет
небезопасное преобразование: несовместимый профиль отклоняется с объяснением.

Режимы
------
1. Локальный — SOCKS5 127.0.0.1:2080. Через клиент идут Chrome с расширением
   и только те программы, где этот прокси указан вручную.
2. Системный — включает прокси Windows и восстанавливает предыдущие настройки
   после остановки.
3. TUN — маршрутизирует весь трафик, требует права администратора и Wintun.

Профили
-------
- hy2:// и hysteria2:// создают профиль sing-box;
- vless:// с type=xhttp и security=tls создаёт профиль Xray;
- JSON автоматически распознаётся как sing-box или Xray.

Комплект
--------
- sing-box.exe + SHA-256;
- xray.exe 26.3.27 + SHA-256;
- wintun.dll + SHA-256;
- тексты лицензий Xray и Wintun.

Сборка
------
Запустите build-release.ps1 в PowerShell 5.1 на Windows с .NET SDK 10.0.302
или новее. Скрипт выполняет тесты, проверяет контрольные суммы и создаёт чистый
self-contained portable ZIP для win-x64.
