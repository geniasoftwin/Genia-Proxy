# Аудит GeniaProxy 3.0.0

Дата: 2026-08-09

## Цель версии

Сделать ежедневную работу проще, не превращая GeniaProxy в универсальный
сетевой комбайн. Версия 3.0 сохраняет WinForms, portable-модель, штатный
sing-box и существующий формат данных.

## Архитектурные изменения

- `OperationCoordinator` стал единой точкой владения текущей операцией и её
  отменой;
- параллельный импорт, запуск, остановка или проверка блокируются одинаково;
- состояние операции доступно диагностике;
- `ProfileInspectionService` отделяет анализ JSON от пользовательского
  интерфейса и тестируется без WinForms;
- новые сервисы не используют сторонние NuGet-пакеты.

## Интерфейс

- выбор профиля оставлен компактным выпадающим списком;
- основные кнопки выровнены и расположены как управление плеером;
- окно уменьшено до 720×460, минимальный размер — 640×380;
- в компактном состоянии остаются выбор профиля, статус и основные команды;
- журнал для новых установок свёрнут по умолчанию.

## Безопасность

- проверка профиля использует ту же нормализацию, лимиты и endpoint-политику,
  что реальный запуск;
- затем конфигурация проверяется доверенным bundled-ядром;
- проверка не включает системный прокси и не запускает соединение;
- диагностический отчёт не содержит содержимого профилей или паролей.

## Проверки

- добавлены тесты взаимоисключения и отмены операций;
- добавлен тест сводки профиля и обнаружения небезопасного TLS;
- сохранены проверки импорта, архивов, атомарной записи и очистки вывода;
- SHA-256 bundled `sing-box.exe` должен совпадать с `sing-box.sha256`.

Полная сборка и визуальная проверка WinForms выполняются на Windows через
Visual Studio или `build-release.ps1`.
