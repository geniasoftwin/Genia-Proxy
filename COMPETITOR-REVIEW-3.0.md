# Конкурентный обзор для GeniaProxy 3.0

Дата исследования: 2026-08-09

## Рассмотренные проекты

| Проект | Сильные стороны | Решение для GeniaProxy |
| --- | --- | --- |
| Hiddify | простой запуск, удалённые профили, автоматический выбор, сведения о подписке | сохранить простой запуск; подписки и автоматический выбор отложить |
| v2rayN | зрелая поддержка Windows/ARM64, несколько ядер, подписанные релизы | перенять строгую координацию и диагностику; несколько ядер не добавлять |
| GUI.for.SingBox | широкий доступ к возможностям sing-box и современная оболочка | сохранить совместимость с готовым JSON, не создавать большой редактор |
| Throne | много форматов импорта, профили, deeplink, chaining | взять идею проверки профиля; chaining/deeplink отложить |
| sing-box-drover | минимальный tray-интерфейс и полный контроль через обычный config | сохранить лёгкость, portable-модель и управление из трея |
| Sing-Box Launcher | предварительный анализ, диагностика, self-healing, subscriptions | взять анализ и самовосстановление; API и traffic profiler не добавлять |

## Что вошло в 3.0

- компактный выпадающий выбор профиля;
- компоновка в стиле компактного музыкального плеера;
- единый координатор взаимоисключающих операций;
- проверка выбранного профиля через безопасную нормализацию и `sing-box check`;
- компактная сводка протоколов и изменений конфигурации;
- сохраняемый диагностический отчёт.

## Что сознательно не вошло

- TUN и запрос административных прав;
- автоматические подписки и сетевой загрузчик конфигураций;
- локальный HTTP API;
- встроенный JSON/маршрутный редактор;
- графики трафика и пер-процессная статистика;
- несколько сетевых ядер.

Эти функции полезны в крупных клиентах, но увеличивают поверхность атаки,
число зависимостей и стоимость сопровождения. Их можно добавлять только при
появлении подтверждённого пользовательского сценария.
