# GeniaProxy 4.2.0: границы продукта

Версия 4.2 поддерживает два ядра (`sing-box` и `Xray`), автоматический выбор
ядра по профилю и три режима: локальный SOCKS5, системный прокси и TUN.
Локальный режим является стандартным: он слушает только
`127.0.0.1:2080` и не перенаправляет приложения, которым прокси не задан.

Дата: 2026-08-14

## Реальные данные интерфейса

| Поле | Источник |
| --- | --- |
| Состояние «Подключение запущено» | локальный/system: SOCKS5 readiness; TUN: adapter/route/DNS/HTTPS readiness выбранного ядра |
| Профиль | имя выбранного файла `data/profiles/*.json` |
| Протокол | типы `outbounds`/`endpoints`, разобранные `ProfileInspectionService` |
| Локальный адрес | фактически переданный приложением `127.0.0.1:<порт>` |
| Системный прокси | состояние, применённое `SystemProxyService` в текущем сеансе |
| Время сеанса | время от подтверждённого запуска локального прокси |
| Журнал | очищенный вывод выбранного ядра и события приложения; тёмное WPF-контекстное меню |

## Границы GeniaProxy 4.2

- страна/город сервера и декоративная карта не определяются;
- скорость загрузки/отдачи и график трафика не измеряются;
- внешний IP, HTTP-версия и задержка показываются только после реальной проверки канала;
- TUN считается запущенным только после фактической readiness-проверки сети;
- sing-box TUN использует `auto_route/strict_route`; GeniaProxy назначает DNS TUN-интерфейсу и IPv4 metric `5`, физический DNS не меняется;
- Xray TUN 4.2.x пока leak-safe только для IPv4: при рабочем IPv6 default route подключение блокируется;
- полноценный IPv6 TUN и WFP/firewall kill-switch остаются следующими этапами.

## Архитектура версии 4.2

- WPF отвечает только за новое главное окно;
- `ConnectionSession` связывает UI с существующими безопасными сервисами;
- WinForms-формы версии 3.0 пока оставлены для проверенных окон ядра и
  диагностики; основной интерфейс, импорт и настройки уже используют WPF;
- для локального QR используется один закреплённый пакет `QRCoder 1.8.0`;
- формат профилей и `data/settings.json` сохранён.
